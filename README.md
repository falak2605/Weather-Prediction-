# 🌦️ Weather Prediction using Machine Learning

## **📌 Project Overview**

This project focuses on predicting weather conditions using multiple machine learning classification algorithms. The workflow includes data preprocessing, feature encoding, model training, and comparative evaluation of different classifiers.

The project compares the performance of:
- Logistic Regression (LR)
- Random Forest (RF)
- Support Vector Machine (SVM)

---

## **📂 Dataset Information**

The dataset contains historical weather observations including:
- Temperature
- Humidity
- Wind Speed
- Precipitation
- Weather Conditions

The dataset was sourced from Kaggle and used for supervised classification tasks. :contentReference[oaicite:0]{index=0}
